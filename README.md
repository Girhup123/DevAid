# DevAid 🚀  
**Every developer’s aid**

DevAid is a free web tool that converts your code into beautiful, shareable images with themes and font controls.

🌐 Live: https://devaid.onrender.com

---

## ✨ Features

- Paste code → get styled image instantly
- Multiple themes (Dracula, Monokai, Solarized, etc.)
- Font size control
- Download image in one click
- No login. No setup. Just use.
